# Support

For template topology, gateway, upload, first-boot setup, and Railway deployment issues, open an issue in this repository. For playback, transcoding, library scanning, clients, and other application behavior, use the [Jellyfin project](https://github.com/jellyfin/jellyfin) and its [documentation](https://jellyfin.org/docs/). For the upload manager, see [dufs](https://github.com/sigoden/dufs). This is a community template and is not supported by the Jellyfin project.
